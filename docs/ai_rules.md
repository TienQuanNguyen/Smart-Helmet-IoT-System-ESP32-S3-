# AI Coding Rules for Smart Helmet Project

1. Do not delete files unless explicitly requested.
2. Do not modify CMakeLists.txt unless explicitly requested.
3. Do not change pin_config.h without confirmation.
4. Do not hardcode WiFi passwords, tokens, API keys.
5. Keep code in C, ESP-IDF style.
6. Use FreeRTOS tasks, queues, event groups where appropriate.
7. Sensor drivers must remain modular.
8. Before large refactor, explain planned file changes.
9. After editing, provide build command and expected result.
10. Never modify files under D:\esp or ESP-IDF installation directory.
